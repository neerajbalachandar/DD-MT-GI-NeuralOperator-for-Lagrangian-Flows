10. NEW GNS-STYLE NOISE
============================================================

Implement in:

training/noise.py

This is NOT assumed to exist in the current code.

Use temporally correlated random-walk noise rather than independent white noise.

For example:

ε_0 ~ N(0,σ²I)
ε_t = ε_{t-1}+η_t

with:

η_t ~ N(0,σ_η²I).

Perturbed state:

S_tilde = S_t + ε_t.

For residual prediction, construct a consistent target:

R*_t =
S^true_{t+1}
− S_tilde
− B(S_tilde,U_tilde,∇U_tilde).

Do not corrupt the input while leaving an inconsistent residual target.

Make it independently switchable:

USE_GNS_NOISE = False/True.
